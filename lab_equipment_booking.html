📖 사용 매뉴얼

🎯 시스템 소개

연구실 실험 예약 시스템에 오신 것을 환영합니다. 이 시스템을 통해 실험 일정을 편리하게 예약하고 관리할 수 있습니다.

  • 장비목록: 위치별로 그룹화된 장비 정보 조회
  • 실험예약: 실험 정보, 위치, 날짜/시간을 선택하여 예약
  • 예약현황: 위치별 전체 예약 현황 확인
  • 내 예약: 나의 예약 내역 조회 및 관리
  • 장비등록신청: 새로운 장비 등록 요청
  • 내 정보: 개인정보 및 비밀번호 수정

📅 실험 예약 방법

1단계: 실험 정보 입력

기본 실험 목록에서 선택하거나, '직접 작성'을 선택하여 실험 제목을 입력합니다.

  • 기본 제공: DNA 추출, PCR 분석, 전기영동, 세포 배양 등
  • 실험 내용은 선택사항으로 간단히 기술 가능

2단계: 실험 위치 선택

드롭다운 메뉴에서 실험 위치를 선택합니다.

  • 분자육종실험실, 가공적성실험실, 생공 중 선택
  • 위치 선택 후 해당 위치의 장비만 필터링되어 표시됩니다

3단계: 날짜 및 시간 선택

달력에서 날짜를 선택하고, 시간을 지정합니다.

  • 주간 종일: 07:00~18:00 전체 시간 자동 선택
  • 24시간: 07:00~24:00 야간 포함 전체 선택
  • 시간 지정: 시작 시간 클릭 → 끝 시간 클릭으로 범위 선택
  • 🌙 18:00 이후는 야간 시간대로 표시됩니다

4단계: 장바구니 활용

선택한 예약을 장바구니에 담아 여러 건을 한 번에 신청할 수 있습니다.

  • 장바구니 담기 버튼으로 항목 추가
  • 🛒 버튼을 클릭하여 장바구니 패널 열기/닫기
  • 일괄 예약하기 버튼으로 한 번에 신청

🗓️ 다일(여러 날) 예약 방법

예시: 21일 오전 9:30부터 22일 오후 3:00까지 예약하기

  1. 캘린더에서 시작 날짜(21일)를 클릭
  2. 시간 그리드에서 시작 시간(09:30)을 클릭
  3. 캘린더에서 종료 날짜(22일)를 클릭
  4. 시간 그리드에서 종료 시간(15:00)을 클릭
  5. 선택 범위가 표시되면 "바로 예약" 또는 "장바구니 담기" 클릭

💡 캘린더에서 선택된 날짜 범위는 연한 배경색으로 표시됩니다.

📆 캘린더 활용하기

예약 현황 확인

  • 캘린더의 각 날짜에 예약 정보가 표시됩니다
  • 예약 위에 마우스를 올리면 상세 정보 툴팁이 나타납니다
  • 예약자, 시간, 위치, 실험 내용 등을 확인할 수 있습니다

내 예약 빠른 취소

  • 캘린더에서 내 예약은 클릭 가능합니다
  • 클릭하면 바로 취소 확인 창이 나타납니다
  • 관리자 승인 없이 즉시 취소됩니다

예약 색상 구분

내 예약(승인) 나의 승인된 예약
내 예약(대기) 나의 승인 대기중 예약
승인됨 다른 사용자의 승인된 예약
대기중 다른 사용자의 대기중 예약

🔬 장비 목록 보기

장비목록 탭에서 등록된 모든 장비를 확인할 수 있습니다.

  • 장비는 위치별로 그룹화되어 표시됩니다
  • 그룹 헤더를 클릭하면 해당 위치의 장비 목록을 접거나 펼 수 있습니다
  • 장비명, 설명, 승인방식, 최대사용시간 정보를 확인할 수 있습니다

📋 예약 상태 안내

대기중 관리자 승인을 기다리는 상태입니다.
승인됨 예약이 승인되어 해당 시간에 실험을 진행할 수 있습니다.
반려됨 예약이 반려되었습니다. 반려 사유를 확인하고 재신청할 수 있습니다.
취소됨 사용자가 예약을 취소한 상태입니다.

🔄 반려된 예약 재신청

예약이 반려된 경우, 내 예약 탭에서 재신청이 가능합니다.

  1. 내 예약 탭으로 이동
  2. 반려된 예약의 재신청 버튼 클릭
  3. 반려 사유를 확인하고 날짜/시간 수정
  4. 재신청 버튼으로 다시 신청

🔬 장비 등록 신청

새로운 장비를 시스템에 등록하고 싶은 경우:

  1. 장비등록신청 탭으로 이동
  2. 장비명(필수) 입력
  3. 위치는 드롭다운에서 선택 (분자육종실험실, 가공적성실험실, 생공)
  4. 설명, 승인방식, 최대사용시간 등 추가 정보 입력
  5. 등록 신청 버튼 클릭
  6. 관리자 승인 후 장비 목록에 추가됩니다

❓ 문의 및 도움말

시스템 사용 중 문제가 발생하거나 추가 도움이 필요한 경우 연구실 관리자에게 문의해 주세요.
