📦 백업 생성
현재 저장된 모든 데이터를 하나의 파일로 백업합니다. 백업 파일은 다른 기기에서 복원할 수 있습니다.
📤 백업 복원
이전에 생성한 백업 파일을 업로드하여 데이터를 복원합니다.
📂
백업 파일을 드래그하거나 클릭하여 선택
.json 또는 .backup 파일
📋 백업 기록
🔗 공유 링크 생성
데이터를 URL로 인코딩하여 공유합니다. 링크를 통해 다른 사람과 데이터를 공유할 수 있습니다.
ℹ️ 공유 링크는 데이터를 URL 파라미터로 포함합니다. 대용량 데이터는 링크가 길어질 수 있으니 파일 공유를 권장합니다.

QR 코드를 스캔하여 데이터를 가져올 수 있습니다

📥 공유 데이터 가져오기
공유받은 링크나 코드를 붙여넣어 데이터를 가져옵니다.
☁️ 클라우드 저장소 연동
클라우드 서비스에 데이터를 백업하고 여러 기기에서 동기화할 수 있습니다.
⚠️ 클라우드 연동은 각 서비스의 공유 폴더 기능을 활용합니다. 아래 버튼을 클릭하면 해당 서비스로 이동합니다.
