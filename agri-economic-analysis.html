농업경영정보시스템경영비·생산비 (amis.rda.go.kr) 통계청 KOSIS농산물생산비조사 aT KAMIS농산물 도·소매 가격 한국은행 ECOS이자율·물가지수 KISTEP표준 할인율(4.5%) 국립종자원종자·품종 정보
1. 기본 정보 입력
과제 개요와 경영 형태를 입력합니다. 경영 형태에 따라 감가상각비·생산비 항목이 자동 제어됩니다.

과제 개요

경영 형태

자가 경영 / 임차 경영 선택에 따라 회계 처리가 달라집니다.
⚠ 임차 경영에서는 감가상각비를 임차료에 반영하므로 별도 계상하지 않습니다. (생산비 추가 항목 — 자가노력비·자기자본이자·자기토지용역비 — 도 비활성화됩니다.)
2. 조수입 계산
주산물·부산물 수량과 단가를 입력합니다. 등급별 가격·다개년 평균 단가 보조 계산기를 제공합니다.

주산물 / 부산물

출처
출처

등급별 가중평균 단가 계산기

등급명·비율(%)·단가를 입력하면 가중평균 단가가 산출됩니다. 적용 시 주산물 단가에 반영됩니다.
등급명비율(%)단가(원/kg)
가중평균 단가: 0 원/kg

3~5개년 평균 단가 계산기

연도별 단가를 입력하면 산술평균이 자동 계산됩니다.
연도단가(원/kg)
산술평균: 0 원/kg

신품종 프리미엄

대조품종 단가 + 프리미엄(%)을 적용해 신품종 단가를 산출합니다.
3. 경영비 입력
항목별 비용(원/10a)과 데이터 출처를 입력합니다. 임차 경영 시 감가상각비는 자동 비활성화됩니다.

경영비 항목

기타 항목 (사용자 정의)

항목명금액(원/10a)출처
경영비 = 종자/종묘 + 비료(무기+유기) + 농약 + 광열동력 + 수리 + 제재료 + (자가 경영 시) 감가상각 + 위탁영농 + 고용노력 + 임차료(토지+기계) + 기타
현재 경영비 합계: 0 원/10a
4. 생산비 추가 항목
자가 경영 시에만 활성화됩니다. 자가 자원의 기회비용을 계상합니다.

자가 자원 용역비

자가노력비 = 가족노동시간 × 농업노임 · 자기자본이자 = 자기자본 × 이자율 · 생산비 = 경영비 + 자가노력비 + 자기자본이자 + 자기토지용역비
5. 수익성 지표
입력값을 기반으로 실시간 계산된 수익성 지표입니다.

핵심 지표

소득 = 조수입 − 경영비 · 순수익 = 조수입 − 생산비 · 소득률 = 소득 ÷ 조수입 × 100
부가가치 = 조수입 − 중간재비(종자·비료·농약·광열동력·수리·제재료·위탁영농) − 감가상각비(자가) · 부가가치율 = 부가가치 ÷ 조수입 × 100

경영비 구성비

6. 투자분석 (다년 과제)
연도별 투자비·편익과 할인율로 NPV·IRR·B/C를 산출합니다.

할인율

연도별 현금흐름 (단위: 천원 또는 원, 일관 유지)

차년도(t)비용편익순현금흐름

투자분석 결과

NPV = Σ (편익ₜ − 비용ₜ) / (1+r)ᵗ · IRR = NPV=0 이 되는 r (이분법 탐색) · B/C = Σ편익ₜ/(1+r)ᵗ ÷ Σ비용ₜ/(1+r)ᵗ
7. 민감도 분석
단가·수량·경영비를 ±10%, ±20% 변동시켜 소득 변화를 분석합니다.

시나리오별 소득 (원/10a)

변동 요인−20%−10%기준+10%+20%

토네이도 차트 (±20% 기준 소득 범위)

손익분기점

손익분기 단가 = 경영비 ÷ 주산물 수량 (소득=0 단가) · 손익분기 수량 = 경영비 ÷ 주산물 단가
8. 보급률 시뮬레이션 (신품종)
연도별 보급률·재배 가능 면적으로 농가소득 파급효과를 추정합니다.

전제 조건

연도별 보급률

연차보급률(%)보급면적(ha)농가소득 증가(원)
보급면적 = 총 재배면적 × 보급률 · 농가소득 증가 = 보급면적(ha) × 10 × 단위면적당 소득증가(원/10a) (1ha = 10 × 10a)

연도별 파급효과

엑셀 다운로드, 인쇄용 보고서 미리보기, 결과 요약 카드를 제공합니다.
