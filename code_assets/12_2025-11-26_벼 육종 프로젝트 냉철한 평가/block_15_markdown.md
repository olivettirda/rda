# ML 모델 검증 보고서

## 1. 데이터 분할
- Train: 240품종 (Japonica 160, Tongil 40, Indica 24, 기타 16)
- Validation: 30품종 (각 재배형 비례)
- Test: 30품종 (최종 평가용, 1회만 사용)

| 도열병저항성 | 0.872 | 0.023 | 0.845-0.901 |

## 3. 독립 Test 셋 결과
- 전체 평균 F1: 0.851 (CV 대비 -2.1%p)
- 재배형별 성능:
  - Japonica: 0.875
  - Tongil: 0.812
  - Indica: 0.763 ← 주의 필요

## 4. 과적합 분석
- Learning Curve: Train-Val gap 5%p 이내 (양호)
- Feature Importance: 상위 5개 마커가 72% 기여 (적정)
- Permutation Test: 15개 중 12개 유의미 (p<0.05)

## 5. 한계 및 주의사항
