# 육종 시뮬레이터 웹앱 슬라이드 제작 자료

## 프레젠테이션 개요

**제목:** AI 기반 벼 육종 시뮬레이터 - 작동 원리와 흐름

**대상:** 육종 원리에 관심 있는 일반인, 농업 관계자

**슬라이드 수:** 15~18장 권장

**톤앤매너:** 친근하고 이해하기 쉬운 설명, 시각적 다이어그램 활용

- **부제:** 육종 시뮬레이터의 작동 원리
- **이미지 제안:** 벼 이삭 + 컴퓨터/AI 아이콘 조합

### 슬라이드 2: 문제 제기
- **제목:** 왜 새 품종 개발이 어려울까?

**핵심 내용:**
- 전통 육종: 10~15년 소요
- 수천 개의 교배 조합 중 성공 확률 낮음
- 후대 결과 예측 불가

**시각화:** 타임라인 그래픽 (10년 → 수확까지의 긴 과정)

### 슬라이드 3: 솔루션 소개

**핵심 내용:**

- 수천 개 조합을 몇 분 만에 분석
- 육종 기간 3~5년 단축 가능

### 슬라이드 9: NSGA-II 알고리즘 설명 (핵심 2)

## 핵심 과학 원리 (일반인용 설명)

### 유전자란?
- 생명체의 특성을 결정하는 "설계도"
- 벼의 경우 약 40,000개의 유전자 보유
- 이 중 육종에서 중요한 것은 약 50~100개

### 교배란?
- 두 품종의 유전자를 섞는 것
- 자손은 양쪽 부모의 유전자를 절반씩 물려받음
- 단, 어떤 유전자를 받을지는 확률적

### 왜 AI가 필요한가?
```
품종 100개가 있다면...
가능한 교배 조합 = 100 × 99 ÷ 2 = 4,950개

각 조합에서...
유전자 50개의 가능한 조합 = 2^50 ≈ 1,000조 개

→ 인간이 계산 불가능, AI 필요!
```

## 실제 사용 예시

### 목표: "도열병에 강하면서 밥맛 좋은 품종 개발"

```
1. 기존 100개 품종 데이터 업로드
2. AI가 학습 (약 30초)
3. "도열병 저항성", "밥맛" 형질 선택
4. NSGA-II 실행 (약 1분)
5. 결과: "일품벼 × 추청벼" 조합 추천
6. 후대 예측: 도열병 저항성 92%, 밥맛 점수 8.5/10
7. 실제 교배 진행 → 기존 대비 3~5년 단축!
```
