    처음이신가요? 3단계
    
        
      
          
    1. 서열 입력 탭에 마커 서열을 붙여넣습니다. 변이는 [A/G] 처럼 대괄호로 쓰고, 양쪽에 flank 를 100–200 nt 둡니다. 헤더에 Chr01:1234567 을 적으면 좌표가 유전체 bp 로 변환됩니다.
      2. 
          
    2. 설계 조건은 기본값(바이오니어 · Tm 57–62 °C · 18–25 nt · amplicon 50–150 bp)으로 시작하면 됩니다. 이미 쓰던 프라이머가 있다면 아래에 붙여넣고 분석 → 이 조건 적용 으로 같은 스타일의 조건을 만듭니다.
      3. 
          
    3. 프라이머 설계를 누르고 결과 탭에서 경고가 적은 세트(Forward / Reverse)를 고른 뒤, 내보내기 탭에서 주문용 엑셀을 받습니다.
