🔬 HRM (High Resolution Melting) 개요

PCR 기반 형광을 이용한 유전자형 분석 기술

💡 핵심 원리

형광 염료가 이중가닥 DNA에 결합하면 강한 형광을 방출합니다. 온도가 상승하면서 DNA가 녹으면(melting) 형광이 감소하는데, 이 변화 패턴(melting curve)이 DNA 서열에 따라 달라집니다.

✅ 장점

  • 빠른 분석 속도
  • 비용 효율적
  • Closed-tube 시스템
  • Heterozygote 검출 가능
  • 프라이머 설계 자유도 높음

⚠️ 제한사항

  • 변이 위치 특정 불가
  • 긴 amplicon 감도 저하
  • 일부 SNP 클래스 구별 어려움
  • DNA 품질/농도 일관성 필요

📊 적용 분야

  • SNP/InDel 유전자형 분석
  • 품종 판별
  • MAS (분자마커선발)
  • 돌연변이 스캐닝
  • DNA 메틸화 분석

⚡ HRM vs KASP 비교

두 마커 시스템의 주요 차이점

🔬 HRM

  • 변이가 Product 내부에 위치
  • 프라이머 설계 제한 적음
  • 범용 형광 염료 사용
  • Heterozygote 자연 검출
  • 다중 변이 동시 감지 가능
  • 장비 의존성 높음

🎯 KASP

  • SNP가 프라이머 3' 말단에 위치
  • 프라이머 설계 제한 많음
  • FAM/HEX 형광 라벨 프라이머
  • 결과가 더 명확함
  • 특정 SNP 타겟팅
  • 전용 프라이머 필요

📈 HRM 분석 원리

단계별 분석 과정

1. PCR 증폭
형광 염료(SYTO9, EvaGreen)와 함께 타겟 영역 증폭
↓
2. 이중가닥 형성
형광 염료가 dsDNA에 결합 → 강한 형광 방출
↓
3. 온도 상승 (65℃ → 95℃)
0.1~0.2℃ 단위로 천천히 온도 상승
↓
4. DNA Melting
dsDNA → ssDNA, 형광 염료 방출 → 형광 감소
↓
5. Melting Curve 생성
온도 vs 형광 → Normalization → Difference plot

🔑 핵심 개념: Tm (Melting Temperature)

DNA 이중나선의 50%가 단일가닥으로 분리되는 온도

SNP나 InDel이 발생하면 stacking energy가 변화하여 Tm이 달라집니다.

🔄 Homoduplex vs Heteroduplex

Melting Curve 형성 원리

Homoduplex (동형이중체)

5' ATCGTGCTA 3' |||||||||| 3' TAGCACGAT 5' → 완전 상보적 결합 → 높은 Tm → 날카로운 melting peak

Heteroduplex (이형이중체)

5' ATCGTGCTA 3' |||| |||| 3' TAGCGCGAT 5' → 미스매치 존재 (T-G) → 낮은 Tm → 넓은 melting peak

Heterozygote 검출 원리 - Melting Curve 패턴

💡 Heterozygote 자연 검출

Heterozygote 샘플에서는 PCR 후 재결합 시 약 50%가 heteroduplex를 형성 → melting curve가 homoduplex와 다른 패턴

✏️ HRM 프라이머 설계 핵심 원칙

성공적인 마커 개발을 위한 가이드라인

✅ 권장사항

  • Product 길이: 100~200 bp (짧을수록 좋음)
  • 변이 위치: Product 중앙에 배치
  • Primer Tm: ~60℃
  • GC 함량: 40~60%
  • GC clamp: 3' 말단에 G/C 2~3개
  • 주변 변이 확인: ±100~200 bp 내 다른 SNP 없음

❌ 피해야 할 사항

  • 300 bp 초과 amplicon
  • 변이가 primer 결합 부위에 위치
  • AT-rich 또는 GC-rich 영역
  • 반복서열, 팔린드롬 서열
  • Primer dimer, hairpin 형성 가능 서열
  • Product 내 다중 변이

변이 위치에 따른 Tm 차이 영향

📏 Product 길이에 따른 영향

짧을수록 SNP 구별이 용이합니다

Product 길이 Tm 차이 구별 용이성 권장 용도
50~100 bp 가장 큼 매우 쉬움 단일 SNP 정밀 검출
100~150 bp 큼 쉬움 일반적 SNP/작은 InDel ✓
150~200 bp 중간 보통 InDel, 강한 SNP
200~300 bp 작음 어려움 큰 InDel에만 권장
300+ bp 매우 작음 매우 어려움 권장하지 않음 ✗

📐 경험 법칙

Product 길이가 2배가 되면, 동일 SNP에 의한 Tm 차이는 약 절반으로 감소합니다.

🎯 SNP 클래스별 Tm 차이

SNP 유형에 따른 HRM 검출 난이도

SNP 클래스별 검출 용이성

클래스 염기 변화 유형 Tm 차이 구별 용이성
Class 1 C↔T, G↔A Transition ~1.0℃ 쉬움 ✓
Class 2 C↔A, G↔T Transversion ~0.5℃ 보통
Class 3 C↔G Transversion (동일 크기) ~0.3℃ 어려움 → UP-HRM
Class 4 A↔T Transversion (동일 크기) <0.2℃ 매우 어려움 → UP-HRM 필수

✅ HRM에 적합

  • Class 1 (C↔T, G↔A): 가장 큰 Tm 차이
  • InDel (1bp 이상): 구별 용이
  • Large InDel (3bp+): 매우 쉬움

⚠️ UP-HRM 권장

  • Class 3 (C↔G): Tm 차이 작음
  • Class 4 (A↔T): Tm 차이 매우 작음
  • Unlabeled Probe 방식 필요!

🧪 UP-HRM (Unlabeled Probe HRM)

어려운 SNP를 검출하기 위한 강화된 방법

💡 UP-HRM이란?

일반 HRM에서 구별이 어려운 SNP (Class 3, 4)를 검출하기 위해 Unlabeled Probe를 추가로 사용하는 방법입니다.

구성 요소 (3 Oligos)
Oligo특징
Forward PrimerTm ~60℃, 낮은 농도 (0.1 μM)
Reverse PrimerTm ~60℃, 높은 농도 (0.5 μM)
Unlabeled ProbeTm ~65℃, 20~35 bp, 3' blocking

⚠️ 핵심: Asymmetric PCR

Forward : Reverse = 1 : 5 (또는 1:10)

→ 과량의 target strand 생성
→ Probe가 target strand에 충분히 hybridization

✅ Probe 설계 조건

  • 길이: 20~35 bp (30 bp 권장)
  • Tm: 65℃ 이상
  • SNP 위치: Probe 중앙에 배치
  • 3' 말단: C3 spacer 또는 Phosphate

📊 UP-HRM Melting Curve 해석

Two-peak Pattern 이해하기

UP-HRM에서의 Two-Peak Pattern

1st Peak: Probe Melting (낮은 온도)

  • Probe-Target duplex의 melting
  • SNP에 의한 Tm 차이가 명확하게 나타남
  • Mismatch → 낮은 Tm / Perfect match → 높은 Tm

2nd Peak: Amplicon Melting (높은 온도)

  • 전체 amplicon의 melting
  • 일반 HRM과 동일
  • 보조적 확인용, Homozygote 간 구별 보완

🛠️ HRM 문제해결 가이드

흔한 문제와 해결 방법

❌ Melting curve가 분리되지 않음

원인:

  • Amplicon이 너무 긺
  • SNP가 Class 3/4
  • 변이 위치가 말단에 가까움

해결:

  • Amplicon 길이 단축 (100bp 이하)
  • UP-HRM 사용
  • 프라이머 재설계
❌ PCR 증폭 실패

원인:

  • 프라이머 설계 문제
  • Annealing 온도 부적절
  • 형광 염료 PCR 저해

해결:

  • BLAST로 특이성 확인
  • Touchdown PCR
  • 염료 없이 먼저 테스트
⚠️ Replicate 간 재현성 낮음

원인:

  • 피펫팅 오차
  • DNA 농도/순도 불균일
  • 형광 염료 분해

해결:

  • Master mix 사용
  • DNA 정량 후 희석
  • 염료 차광 보관
⚠️ UP-HRM Probe peak 안 보임

원인:

  • Probe 농도 부족
  • Asymmetric PCR 실패
  • HRM 시작 온도 높음

해결:

  • Probe 농도 증가 (0.5 μM)
  • Primer 비율 확인 (1:5~1:10)
  • HRM 시작 40℃부터

🧮 Primer/Probe Tm 계산기

실용적인 도구

Tm 계산
Tm 계산 공식 참고

Wallace Rule (14-20 bp)

Tm = 2(A+T) + 4(G+C)

정확도: ±5℃

Salt-adjusted (일반 PCR)

Tm = 81.5 + 16.6×log₁₀[Na⁺] + 0.41×(%GC) - 600/N

정확도: ±3℃

권장 Tm 범위

  • Primer: 58~62℃
  • UP-HRM Probe: 65℃ 이상
  • F/R Tm 차이: < 2℃
