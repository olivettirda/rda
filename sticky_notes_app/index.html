📖 사용 설명서

기본 사용법

  • 새 메모 만들기: 오른쪽 아래 + 버튼 클릭 또는 Ctrl + N
  • 메모 이동: 메모의 가장자리를 드래그
  • 메모 크기 조절: 메모 우하단 모서리 드래그
  • 메모 색상 변경: 버튼 클릭
  • 메모 삭제: 버튼 클릭

텍스트 편집

  • 편집 모드: 버튼을 클릭하면 서식 도구가 표시됩니다
  • 글꼴/크기: 드롭다운 메뉴에서 선택
  • 굵게: Ctrl + B
  • 기울임: Ctrl + I
  • 밑줄: Ctrl + U
  • 정렬: ⫷ (왼쪽), ☰ (가운데), ⫸ (오른쪽)
  • 말머리: • 버튼으로 불릿 리스트 추가
  • 체크박스: ☐ 버튼으로 체크박스 추가
  • 우클릭 메뉴: 텍스트 선택 후 우클릭하면 플로팅 서식 도구 표시

그룹 기능

  • 핀 표시: 메모를 더블클릭하면 핀이 나타납니다
  • 연결하기: 핀을 드래그하여 다른 메모에 놓으면 빨간 실로 연결됩니다
  • 그룹 생성: 메모들이 연결되면 그룹 생성 여부를 묻습니다
  • 빈 그룹: 그룹 패널에서 "새 그룹 만들기"로 빈 그룹 생성 가능
  • 그룹에 추가: 메모를 그룹 패널의 그룹 항목에 드래그하여 추가
  • 그룹 패널: 우측 상단의 그룹 버튼으로 열기

메모 전달

  • 전달하기: 버튼을 클릭하여 다른 사용자에게 메모 전달
  • 전달 표시: 전달한 메모는 왼쪽 위에 표시가 됩니다
  • 전달 취소: 전달한 메모 표시 클릭 시 전달 취소 가능
  • 받은 메모: 전달받은 메모는 아이콘으로 표시됩니다

👤 프로필 및 설정

  • 프로필: 우측 상단 아바타 클릭 → 프로필
  • 정보 수정: 이름과 소속 변경 가능
  • 비밀번호 변경: 현재 비밀번호 확인 후 변경
  • 백업: JSON 또는 엑셀(CSV)로 메모 내보내기
  • 복원: JSON 파일로 메모 불러오기
  • 회원 탈퇴: 모든 데이터가 삭제됩니다 (되돌릴 수 없음)
