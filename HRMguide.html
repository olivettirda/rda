HRM (High Resolution Melting) 분석이란?

HRM은 PCR 기반 형광을 이용한 마커 검정 방법으로, 이중가닥 DNA의 melting curve를 분석하여 SNP, InDel 등의 유전적 변이를 검출합니다.

💡 핵심 원리

형광 염료가 이중가닥 DNA에 결합하면 강한 형광을 방출합니다. 온도가 상승하면서 DNA가 녹으면(melting) 형광이 감소하는데, 이 변화 패턴(melting curve)이 DNA 서열에 따라 달라집니다.

✅ 장점

  • 빠른 분석 속도
  • 비용 효율적
  • Closed-tube 시스템
  • Heterozygote 검출 가능
  • 프라이머 설계 자유도 높음

⚠️ 제한사항

  • 변이 위치 특정 불가
  • 긴 amplicon 감도 저하
  • 일부 SNP 클래스 구별 어려움
  • DNA 품질/농도 일관성 필요

📊 적용 분야

  • SNP/InDel 유전자형 분석
  • 품종 판별
  • MAS (분자마커선발)
  • 돌연변이 스캐닝
  • DNA 메틸화 분석
HRM vs KASP 비교

🔬 HRM

  • 변이가 Product 내부에 위치
  • 프라이머 설계 제한 적음
  • 범용 형광 염료 사용
  • Heterozygote 자연 검출
  • 다중 변이 동시 감지 가능
  • 장비 의존성 높음

🎯 KASP

  • SNP가 프라이머 3' 말단에 위치
  • 프라이머 설계 제한 많음
  • FAM/HEX 형광 라벨 프라이머
  • 결과가 더 명확함
  • 특정 SNP 타겟팅
  • 전용 프라이머 필요

🔑 핵심 개념: Tm (Melting Temperature)

DNA 이중나선의 50%가 단일가닥으로 분리되는 온도. SNP나 InDel이 발생하면 stacking energy가 변화하여 Tm이 달라집니다.

Heteroduplex와 Homoduplex

Homoduplex (동형이중체)

5' ATCGTGCTA 3' |||||||||| 3' TAGCACGAT 5' → 완전 상보적 결합 → 높은 Tm → 날카로운 melting peak

Heteroduplex (이형이중체)

5' ATCGTGCTA 3' |||| |||| 3' TAGCGCGAT 5' → 미스매치 존재 (T-G) → 낮은 Tm → 넓은 melting peak

Heterozygote 검출 원리

Heterozygote 샘플에서는 PCR 후 재결합 시 약 50%가 heteroduplex를 형성합니다. 이로 인해 melting curve가 homoduplex와 다른 패턴을 보여 자연스럽게 구별됩니다.

형광 염료 종류
염료 특징 농도 장점 단점
SYTO9 3세대 포화염료 1.5 μM 높은 감도, PCR 저해 적음 유리 표면 부착
EvaGreen 3세대 포화염료 1× (키트) 고감도, 범용성 일부 PCR 저해

⚠️ 주의사항

  • SYTO9는 유리에 부착되므로 플라스틱 튜브만 사용
  • 형광 염료는 빛에 민감하므로 차광 보관
  • SYBR Green I은 포화농도 사용 불가로 HRM에 부적합
HRM 프라이머 설계 핵심 원칙

✅ 권장사항

  • Product 길이: 100~200 bp (짧을수록 좋음)
  • 변이 위치: Product 중앙에 배치
  • Primer Tm: ~60℃
  • GC 함량: 40~60%
  • GC clamp: 3' 말단에 G/C 2~3개
  • 주변 변이 확인: ±100~200 bp 내 다른 SNP 없음

❌ 피해야 할 사항

  • 300 bp 초과 amplicon
  • 변이가 primer 결합 부위에 위치
  • AT-rich 또는 GC-rich 영역
  • 반복서열, 팔린드롬 서열
  • Primer dimer, hairpin 형성 가능 서열
  • Product 내 다중 변이
Product 길이에 따른 영향
Product 길이 Tm 차이 구별 용이성 권장 용도
50~100 bp 가장 큼 매우 쉬움 단일 SNP 정밀 검출
100~150 bp 큼 쉬움 일반적 SNP/작은 InDel
150~200 bp 중간 보통 InDel, 강한 SNP
200~300 bp 작음 어려움 큰 InDel에만 권장
300+ bp 매우 작음 매우 어려움 권장하지 않음

📐 경험 법칙

Product 길이가 2배가 되면, 동일 SNP에 의한 Tm 차이는 약 절반으로 감소합니다.

SNP 클래스별 Tm 차이

SNP 유형에 따라 HRM에서 검출되는 Tm 차이가 달라집니다. 이는 염기 간 수소결합 수와 stacking energy 차이에 기인합니다.

클래스 염기 변화 유형 Tm 차이 구별 용이성
Class 1 C↔T, G↔A Transition (피리미딘↔퓨린) ~1.0℃ 쉬움
Class 2 C↔A, G↔T Transversion ~0.5℃ 보통
Class 3 C↔G Transversion (동일 크기) ~0.3℃ 어려움
Class 4 A↔T Transversion (동일 크기) <0.2℃ 매우 어려움

✅ HRM에 적합

  • Class 1 (C↔T, G↔A): 가장 큰 Tm 차이
  • InDel (1bp 이상): 구별 용이
  • Large InDel (3bp+): 매우 쉬움

⚠️ UP-HRM 권장

  • Class 3 (C↔G): Tm 차이 작음
  • Class 4 (A↔T): Tm 차이 매우 작음
  • Unlabeled Probe 방식 권장
변이 유형별 영향
변이 유형 HRM Score 영향 검출 감도 비고
1 bp Deletion 낮음 보통 SNP보다 영향 작을 수 있음
Single base change (SNP) 중간 양호 클래스에 따라 다름
3 bp Insertion 높음 우수 명확한 curve 차이
9 bp Insertion 매우 높음 매우 우수 가장 쉬운 검출

📊 상대적 영향도 순서

1bp Deletion < Single base change < 3bp Insertion < 9bp Insertion

HRM은 DNA 혼합물에서 소수 대립유전자를 검출할 수 있습니다. 검출 감도는 변이 유형과 amplicon 특성에 따라 달라집니다.

UP-HRM (Unlabeled Probe HRM) 개요

💡 UP-HRM이란?

일반 HRM에서 구별이 어려운 SNP (Class 3, 4)를 검출하기 위해 Unlabeled Probe를 추가로 사용하는 방법입니다. Probe가 타겟 SNP 부위에 직접 결합하여 mismatch 유무에 따른 Tm 차이를 극대화합니다.

구성 요소 (3 Oligos)

Oligo 특징
Forward Primer Tm ~60℃, 낮은 농도 (0.1 μM)
Reverse Primer Tm ~60℃, 높은 농도 (0.5 μM)
Unlabeled Probe Tm ~65℃, 20~35 bp, 3' blocking

Asymmetric PCR 원리

Forward와 Reverse primer의 농도를 1:5 ~ 1:10으로 불균일하게 설정합니다.

→ 과량의 target strand 생성

→ Probe가 target strand에 충분히 hybridization

Unlabeled Probe 설계 가이드

✅ Probe 설계 조건

  • 길이: 20~35 bp (30 bp 권장)
  • Tm: 65℃ 이상 (primer보다 5℃ 높게)
  • SNP 위치: Probe 중앙에 배치
  • 3' 말단: C3 spacer 또는 Phosphate 처리
  • SNP 염기: Reference allele로 설계

⚠️ 주의사항

  • 3' blocking 필수 (polymerase 연장 방지)
  • Probe가 primer와 겹치지 않도록
  • 이차구조 형성 서열 피하기
  • GC 함량 40~60% 유지

UP-HRM 프라이머/프로브 배치

UP-HRM Melting Curve 해석

📊 Two-peak Pattern

UP-HRM에서는 두 개의 melting peak가 관찰됩니다:

1st Peak: Probe Melting (낮은 온도)

  • Probe-Target duplex의 melting
  • SNP에 의한 Tm 차이가 명확하게 나타남
  • Mismatch → 낮은 Tm
  • Perfect match → 높은 Tm

2nd Peak: Amplicon Melting (높은 온도)

  • 전체 amplicon의 melting
  • 일반 HRM과 동일
  • 보조적 확인용
  • Homozygote 간 구별 보완
예시: SNP T/C 검출 Probe 서열 (Reference = T): 5'-...ATGTCGA...-3' (3'-Phosphate) Sample 1 (TT homozygote): Probe: ATGTCGA Target: TACAGCT → Perfect match → 높은 Tm (예: 67℃) Sample 2 (CC homozygote): Probe: ATGTCGA Target: TACGGCT → Mismatch (T-G) → 낮은 Tm (예: 60℃) Sample 3 (TC heterozygote): → 두 개의 probe peak (60℃ + 67℃) 또는 중간 위치의 넓은 peak

  • Annealing 온도 부적절
  • MgCl₂ 농도 부적절

Heterozygote 검출 실패

가능한 원인

  • Heteroduplex 형성 불충분
  • 급냉 단계 누락
  • SNP 유형이 Tm 차이 작음
  • 분석 소프트웨어 설정 문제

해결 방법

  • 95℃ 30초 → 40℃ 60초 급냉 추가
  • HRM 전 heteroduplex 단계 확인
  • UP-HRM 사용
  • Normalization 범위 재설정
UP-HRM에서 Probe peak 안 보임

가능한 원인

  • Probe 농도 부족
  • Asymmetric PCR 실패
  • Probe Tm이 너무 낮음
  • Probe annealing 시간 부족
  • HRM 시작 온도가 너무 높음

해결 방법

  • Probe 농도 증가 (0.5 μM)
  • Primer 비율 확인 (F:R = 1:5~1:10)
  • Probe 길이 증가 (30~35 bp)
  • 40℃ hold 시간 증가 (2~3분)
  • HRM 시작 온도 낮춤 (40℃부터)
품질 관리 체크리스트
  • DNA 품질: A260/280 = 1.8~2.0, A260/230 > 1.5
  • DNA 농도: 모든 샘플 동일 농도로 희석 (예: 25 ng/μL)
  • Negative control: 매 실험 포함 (No template)
  • Positive controls: 각 genotype별 known sample 포함
  • Replicate: 최소 2~3회 반복 (triplicate 권장)
  • HRM 전 PCR 확인: Gel 또는 real-time curve로 증폭 확인
  • Normalization: Pre-melt/Post-melt 영역 적절히 설정

Salt-adjusted Tm (일반 PCR)
공식: Tm = 81.5 + 16.6×log₁₀[Na⁺] + 0.41×(%GC) - 600/N 변수: [Na⁺] = 나트륨 이온 농도 (M) %GC = GC 함량 (%) N = 서열 길이 (bp) 적용: 일반 PCR primer 정확도: 중간 (±3℃)
Nearest-Neighbor (NN) 방법
공식: Tm = (ΔH - 3.4) / (ΔS + R×ln(Ct/4)) - 273.15 + 16.6×log₁₀[Na⁺] 변수: ΔH = 엔탈피 변화 (kcal/mol) ΔS = 엔트로피 변화 (cal/mol·K) R = 기체상수 (1.987 cal/mol·K) Ct = 총 strand 농도 (M) 적용: 정밀한 Tm 예측 정확도: 높음 (±1℃)
