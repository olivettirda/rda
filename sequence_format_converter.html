📖 지원 포맷 안내

🧬 FASTA

가장 널리 사용되는 시퀀스 포맷. 헤더는 > 로 시작.

>Seq1 description ATGCGATCGATCG >Seq2 ATGCGATCGATCG

🌳 PHYLIP

계통수 분석용. 첫 줄에 시퀀스 수와 길이 표시. 이름 10자 제한.

2 13 Seq1 ATGCGATCGATCG Seq2 ATGCGATCGATCG

📊 NEXUS

MrBayes, PAUP* 등에서 사용. 블록 구조로 메타데이터 포함 가능.

#NEXUS BEGIN DATA; DIMENSIONS NTAX=2 NCHAR=13; FORMAT DATATYPE=DNA GAP=-; MATRIX Seq1 ATGCGATCGATCG Seq2 ATGCGATCGATCG ; END;

📐 CLUSTAL

ClustalW/X 정렬 출력 형식. 보존도 표시 포함.

CLUSTAL W (1.83) multiple sequence alignment Seq1 ATGCGATCGATCG Seq2 ATGCGATCGATCG *************

📁 MSF

GCG 패키지 형식. 체크섬 포함.

PileUp MSF: 13 Type: N Name: Seq1 Len: 13 Name: Seq2 Len: 13 // Seq1 ATGCGATCGATCG Seq2 ATGCGATCGATCG

📋 Table

탭으로 구분된 이름과 시퀀스. 엑셀에서 바로 사용 가능.

Seq1 ATGCGATCGATCG Seq2 ATGCGATCGATCG
